# Правило: адреса объектов не публикуем полностью

Жёсткое правило проекта, действует для всего: сайт, бот, каталог, карты, посты, выгрузки.

## Что можно показывать

- город / посёлок;
- район (Приморский, Жовтневый, Орджоникидзевский, Ильичёвский, Левобережный);
- **улицу** или переулок, проспект;
- ориентир («рядом школа № 26», «5 минут до моря») — если он не выдаёт конкретный дом.

## Что нельзя

- **номер дома**, корпус, строение, квартиру (`д. 12`, `12а`, `12/1`, `кв. 45`);
- **номер участка**, сотки с привязкой к адресу (`участок 5`);
- **точку на карте** по конкретному объекту: метка (`pt=`) на доме или участке;
- координаты с точностью выше 3 знаков после запятой (3 знака ≈ 100 м — допустимо).

Точный адрес сообщается только по телефону и только после разговора с клиентом.

## Как это реализовано

| Где | Что сделано |
|---|---|
| `js/address.js` | `window.publicAddress(addr)` — обрезает номер дома/участка, используется в карточках каталога, главной, избранном, на странице объекта и в `description` |
| `object.html` | мини-карта без метки (`ll` + `z=14`), подпись «На карте — район расположения. Точный адрес и показ — по телефону» |
| `js/data.json` | координаты округлены до 3 знаков (≈100 м) |
| `worker/src/github.js` | при добавлении объекта из бота адрес проходит ту же очистку (`publicAddress`) |
| бот `/add` | подсказка: «адрес: район и улица, без номера дома» |

## Если добавляете новый блок (карту, районные страницы, «похожие»)

- никаких `pt=` и точных координат объекта — только центр улицы/района;
- адрес в тексте пропускать через `publicAddress()`;
- в микроразметку (`JSON-LD`) не класть номера домов, только `addressLocality` и `streetAddress` без номера.
