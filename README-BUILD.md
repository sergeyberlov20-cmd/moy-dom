# Сборка сайта (локально)

Эта папка — **исходники**. На GitHub уезжает только сжатая сборка.

## Что где

| Папка | Назначение |
|---|---|
| `C:\Users\nice\Desktop\moy-dom-src` | исходники: правим здесь (HTML/CSS/JS как есть) |
| `…\moy-dom-src\tools\build.js` | сборщик: минификация + обфускация + паспорт сборки |
| `…\moy-dom-src\tools\key.txt` | **ключ подписи** (создаётся сам, в git не попадает) |
| `…\moy-dom-src\dist` | результат сборки (только для проверки) |
| `C:\Users\nice\Desktop\moy-dom-repo` | то, что публикуется на GitHub Pages (минифицированное) |

## Как менять сайт

```powershell
cd C:\Users\nice\Desktop\moy-dom-src
# 1) правим файлы здесь (index.html, js/main.js, css/style.css …)
# 2) собираем и раскладываем в репозиторий
node tools\build.js --publish
# 3) проверяем подпись (по желанию)
node tools\verify.js
# 4) отправляем на GitHub
cd C:\Users\nice\Desktop\moy-dom-repo
git add -A
git commit -m "обновление сайта"
git push
```

Только собрать без публикации: `node tools\build.js` → результат в `dist\`.

## Что делает сборка

* **CSS** — убирает комментарии и пробелы.
* **JS** — убирает комментарии/пробелы, заменяет `true/false` на `!0/!1`; каждый файл проверяется через `node --check`,
  если проверка не прошла — файл остаётся оригинальным (в консоли будет список таких файлов).
* **HTML** — убирает комментарии и лишние пробелы между тегами; `<script>`/`<style>` сжимаются отдельно,
  а `application/ld+json` (разметка для поиска) не трогается.
* **worker/** — копируется без изменений (его деплоит wrangler, код должен остаться рабочим).
* **build-info.json** — паспорт: SHA-256 каждого файла + HMAC-подпись ключом `tools/key.txt`.
  По нему можно проверить, что на сервере именно наша сборка: `node tools\verify.js`.

## Что «ключ» даёт и чего не даёт

* Даёт: подтверждение подлинности сборки (никто не подменит файлы незаметно) и «соль» для сборки.
* Не даёт: **шифрования**. Статический сайт браузер обязан прочитать, поэтому 100% скрыть код нельзя —
  можно только сделать его нечитаемым. Исходники при этом остаются здесь, на ПК.

## Откат

Перед первой публикацией создана ветка `backup-before-obf` в репозитории:

```powershell
cd C:\Users\nice\Desktop\moy-dom-repo
git checkout backup-before-obf -- .
```

## Защита контента

`js/protect.js` — жёсткий режим (выделение и копирование запрещены, правый клик по фото отключён,
водяной знак на фото). Настройки — в `CONFIG` в начале файла; `strict: false` возвращает мягкий режим.
Панель `/admin/` защита не затрагивает.
